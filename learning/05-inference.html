⑤ 推理与采样：先读题，再一个字一个字写

提示词 384 个 token，被切成 128 一块共 3 块，逐块推进（--prefill-chunk 128）。每块里所有位置同时算注意力；读完后进入 decode，每次只算 1 个新 token（靠 KV Cache 复用历史）。

if(!constrained && temperature==0 && repetition_penalty==1)
    return at::max(logits).index;             // 贪心：直接取最大

for each token i:
    if(repeated.count(i)) value = value<0 ? value*penalty : value/penalty;
    // 温度
    p = exp((value - best) / temperature);
// top-k 只保留前 k 个；top-p 再按累计概率截断
// 最后：法一取最大值 / 法二按概率随机抽
JSON 模式还会先套一层 grammar 掩码：把“不合语法”的 token 直接置为不可选，保证输出一定是合法 JSON。
一句话抓住：Prefill 是“读题”（一次读很多、只做一遍），Decode 是“写字”（一次一个、反复做）。采样则决定这字是“最稳的”（贪心）还是“有随机性的”（温度 + top-k/top-p）。
