⑥ 张量并行：把一个大矩阵切给多张卡

本项目的首要配置是 TP=2（两张 A100）。一个权重矩阵太大、单卡放不下或算得慢，就把它沿某个方向切开，每张卡只存一半、算一半。难点在于：算完之后怎么把结果拼回完整的样子。

选择 TP： 切分方式：

rank0 持有 rank1 持有 （TP=4 时再细分给 rank2/rank3）
本项目的切分规则在 tools/format_utils.py · partition()：chunk(values) 切第 0 维（输出），用于 gate/up/q/k/v_proj；chunk(values,1) 切第 1 维（输入），用于 down_proj/o_proj/out_proj。

两种切法，代价不同

列并行 切输出

每张卡算出一部分输出通道。比如 q_proj 24 个头，TP=2 时每卡算 12 个头的 Q。好处：不需要通信就能各自往下算（直到需要拼的地方）。

行并行 切输入

每张卡拿到输入的一部分，算出的是“部分和”。比如 o_proj，两卡各算一半贡献，必须 AllReduce 相加才是完整结果。

AllReduce：把“部分和”合并成“全和”

行并行算完，每张卡手里都是一个不完整的结果。要对位相加。点按钮看它怎么合：

两张卡各持一半贡献
⇅ NCCL AllReduce
对应 engine.cpp · sum()：ncclAllReduce(..., ncclFloat, ncclSum, ...)。每个 rank 都会得到相同的完整结果（这是“All”的含义），于是后续每层可以继续各算各的。
// engine.cpp · Engine::sum()  —— 张量并行的“缝合点”
ncclAllReduce(buffer, buffer, count, ncclFloat, ncclSum, comm, stream);
// 每个 rank 把各自的部分和累加，结果广播回所有 rank

// 于是 linears 里：
Tensor linear(x, w, reduce=true) { auto y = fp8_linear(x, w, s);
    return reduce ? sum(y) : y; }   // 行并行层：reduce=true
除了 AllReduce，TP 还需要在层间 广播采样出的 token（每个 rank 要吃到同一个 token 才能继续同构计算）——见 worker.cpp 里的 MPI_Bcast(&token, ...)。
一句话抓住：张量并行 = “切矩阵 + 算完把结果缝回去”。切输出（列并行）通常不用通信，切输入（行并行）必须 AllReduce。分界点就是引擎里 reduce=true/false 的那个开关。
