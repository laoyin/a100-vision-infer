⑨ 混合注意力：64 层里，只有 16 层用"真"注意力

这是本项目最独特的架构。标准 Transformer 每层都是全注意力（开销随序列长度平方增长）。这里做了混合：每 4 层里，3 层用轻量的线性注意力（Gated DeltaNet），第 4 层才用全注意力。下面逐块拆开看。

为什么不全都用全注意力？

全注意力要让每个 token 和之前所有 token 两两比较，代价 \(\propto T^2\)；线性注意力只维护一个固定大小的状态，代价 \(\propto T\)。序列越长，差距越夸张。拖动下面的 T 看差距：

Gated DeltaNet 内部：一次 forward 走了哪几步

线性注意力层不是"不算注意力"，而是换了一套机制。点每一步看说明：

// engine.cpp · delta_attention()（核心几行）
int K=linear_key_head_dim, V=linear_value_head_dim;     // 128, 128
int HK=linear_num_key_heads/world, H=linear_num_value_heads/world; // 16/…, 48/…
int kernel=linear_conv_kernel_dim;                      // 4

auto mixed = projected.narrow(-1,0,C);                  // 融合权重一次性投影出 q,k,v,z,b,a
conv = conv_decode(...) | silu(conv1d(...));            // 深度可分离卷积(kernel=4) + SiLU
q = fused_l2(q).repeat_interleave(H/HK,1);              // q,k 逐头 L2 归一化，再扩到 48 头
k = fused_l2(k).repeat_interleave(H/HK,1);
g    = -exp(A_log) * softplus(a + dt_bias);             // 衰减门（负值）
beta = sigmoid(b);                                      // 写入强度 ∈ (0,1)
result = delta_scan_fast(q,k,v,g,beta, s.recurrent);    // ← 递归状态更新（下一节）
result = norm(result) * silu(z);                        // 输出门控 + RMSNorm
return linear(result, out_proj, true);                  // 行并行 → AllReduce
注意：g 是负数，作用在状态上相当于"按 token 衰减记忆"；beta 控制这一步写入多少。z 是一条输出门控（swish），和全注意力里的 gate.sigmoid() 异曲同工。

核心：delta 规则，一个"会遗忘的记忆矩阵"

状态 state[H,K,V] 里每个头都有一个 K×V 的矩阵（真实是 128×128）。每来一个 token，就做四件事：先衰减 → 用 key 去读记忆 → 算出和目标值的差 delta → 把 delta 写回记忆。下面用 6×6 的缩小版演示（点"下一个 token"）：

点"下一个 token"开始。每一拍：state ×= decay → 用 k 读出 memory → delta=(v−memory)·β → state += k⊗delta。
对应 kernels.cu · scan（正确优先）与 optimized.cu · register_scan<128>（状态留在寄存器）。状态是 FP32 的，因为递归会累积误差；输入 q/k/v 是 BF16。
一句话抓住：混合注意力 = "便宜的多用、贵的少用"。48 层线性注意力负责日常信息流（省显存、省算力、不存 KV Cache），16 层全注意力定期"全局对齐"一次。两者交替，兼顾长序列效率与建模能力。
